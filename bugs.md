# Bugs

- **`ContadorComponent` pisa el mismo contador**: `cargarContadorEspaciosDeportivos`, `cargarContadorModalidadesDeportivas` y `cargarContadorRutas` escriben todas en `contadores.deportivos` en vez de sus propios campos (`complementarios`, `modalidades`, `rutas`).
- **`CensoService` usa el mismo endpoint para contadores distintos**: `numeroEspaciosComplementarios`, `numeroModalidadesDeportivas` y `numeroRutas` llaman a `/instalaciones/contador` (copia/pega), no a endpoints específicos.
- **`WidgetComponent.generarEnlace()`** construye la URL con `'xxxxxxx/mapa-widget?...'` (placeholder sin resolver).
- **Contenido de `configuraciones` sin soporte multiidioma (pendiente de backend)**: los textos que se muestran vía `[innerHTML]` (planes locales, acerca del inventario, aviso legal, privacidad) vienen de la tabla `configuraciones` del backend como un único bloque de HTML en español (p.ej. `GET /configuraciones?nombre=planes` incluye el título "Listado por municipios Andaluces:" embebido dentro del `valor`). El frontend ya soporta ES/EN vía `ngx-translate`, pero no puede traducir este contenido porque no es texto de plantilla Angular. Pedir al equipo de backend que: (a) añada un campo de idioma a `configuraciones` y devuelva el valor según `Accept-Language`/parámetro, o (b) separe los textos traducibles del HTML de maquetación para poder traducirlos desde el frontend.
- **`InstalacionesComponent` (`/instalaciones`) carga el listado completo sin paginar**: `cargarInstalaciones()` llama a `CensoService.cargarInstalaciones(this.filtros)` sin ningún parámetro de página/tamaño, y el backend devuelve las ~19468 instalaciones completas en una sola respuesta. Esto renderiza ~19468 `<li>` dentro de `.property-listing`, lo que estira el sidebar sticky (`#filtrosResultadoBusqueda`, con el botón "Cambiar búsqueda") a una altura de columna absurda (millones de píxeles), dejándolo prácticamente inalcanzable sin un scroll gigantesco. Además el markup de paginación visible (`<ul class="pagination">` con enlaces `/busqueda-listado?Page=1..150`) es estático/hardcodeado y no está conectado a ninguna lógica real de paginación. Hace falta implementar paginación real: pasar página/tamaño a `CensoService.cargarInstalaciones`, y conectar los controles de paginación del template a esos parámetros.
